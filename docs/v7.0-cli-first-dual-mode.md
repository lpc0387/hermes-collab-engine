## 四、双模式详细设计

### 4.1 Mode 1: No-Leader (V4 平行协作)

**你（Hermes Agent）是调度主体**——不经 engine.run()，你直接驱动命令行。

#### 4.1.1 调度流程

```
用户输入: "实现一个 Flask 待办事项应用"

你分析 → 分解为子任务:

  1. [codex]     项目骨架 + models.py + storage.py
  2. [opencode]  API 路由 + app.py
  3. [claude-code] 前端 HTML + JavaScript
  4. [opencode]  测试用例
  5. [hermes]    审查所有产出（peer review）

→ 逐个 dispatch:
  $ opencode run "实现 Flask todo app 的 models.py..." ⋯
  → 收集 stdout
  → 下一个
  → 收集 stdout
  → ⋯

→ 收集后组织 peer review:
  claude-code 审 opencode 的产出 (file-edit 能力)
  opencode 审 codex 的产出 (test-run 能力)
  hermes 终审所有

→ 你终检 → 整合 → 交付
```

#### 4.1.2 实现

```python
# engine/no_leader.py (新增)
class NoLeaderDispatcher:
    """
    No-Leader 模式下你（Hermes Agent）用的调度器。
    直接调用 agent CLI subprocess，不经过 CollabEngine.run()。
    """
    
    def dispatch(self, agent: str, task: str, model: str | None = None) -> WorkerResult:
        backend = get_backend(agent)
        cmd = backend.build_command(
            prompt=task,
            model=model,
            allowed_tools=['file-edit', 'git-ops'],
            provider=None,
            reasoning=False,
        )
        proc = subprocess.run(cmd, capture_output=True, text=True, timeout=300)
        return WorkerResult(
            agent=agent,
            ok=proc.returncode == 0,
            stdout=proc.stdout,
            stderr=proc.stderr,
            duration=...,
        )
    
    def peer_review(self, target: str, target_agent: str, reviewer: str) -> ReviewResult:
        """选 reviewer 对 target 的产出做评审"""
        review_prompt = f"请评审以下代码（由 {target_agent} 编写）:\n\n{target}\n\n评审标准: correctness/completeness/code_quality"
        result = self.dispatch(reviewer, review_prompt)
        return self._parse_review(result.stdout)
```

### 4.2 Mode 2: Leader (WBS + Guardian)

**你（Hermes Agent）是 Guardian**——引擎处理 WBS 生命周期，你实时决策。

#### 4.2.1 调度流程

```
用户输入 → CollabEngine.run()
  ├─ Planner 分解 (WBS)
  ├─ CapabilityRouter 选 worker (基于能力匹配)
  ├─ 并行 dispatch 到所选 worker agent
  ├─ Guardian 线程监控每个 worker
  │   └─ CLI 推送事件:
  │       → [wbs-1] codes: models.py 编写中...
  │       → [wbs-2] claude: 前端开发中...
  │       → [GUARDIAN] ⚠️ wbs-1 已运行 120s 无输出
  │         是否中断？[y/N] >
  ├─ 你决策 → continue / interrupt / recover
  ├─ 完成 → Aggregator 汇总
  └─ 交付
```

#### 4.2.2 Worker Agent 选择

Leader 模式下，worker agent 由两部分决定：

1. **预选过滤** — 用户在启动时选的 agent 列表（`opc leader --agent opencode,claude-code`）
2. **能力路由** — engine 在 dispatch 时从预选列表中选能力匹配度最高的

```python
# engine/capabilities.py
CAPABILITIES = {
    "opencode": {
        "capabilities": {"general-coding": 8, "file-edit": 7, "test-run": 7, ...},
    },
    "claude-code": {
        "capabilities": {"file-edit": 9, "mcp-host": 9, "design": 7, ...},
    },
    "codex": {
        "capabilities": {"scaffold": 8, "prototype": 7, "execution": 8, ...},
    },
    "hermes": {
        "capabilities": {"planning": 9, "analysis": 9, "review": 8, ...},
    },
}

def select_best_agent(capability: str, available: list[str]) -> str:
    """从可用 agent 中选能力匹配度最高的"""
    best = available[0]
    best_score = 0
    for name in available:
        profile = CAPABILITIES.get(name, {})
        score = profile.get("capabilities", {}).get(capability, 0)
        if score > best_score:
            best = name
            best_score = score
    return best
```

#### 4.2.3 Guardian CLI 协议

Guardian 事件不再走 web SSE，改为 CLI stdout 实时推送 + stdin 交互：

```python
# engine/cli_protocol.py
class CLIGuardianProtocol:
    """替代 web SSE 的 guardian CLI 交互"""
    
    def emit_stream(self, node_id: str, detail: str):
        print(f"  → [{node_id}] {detail}")
    
    def emit_attention(self, node_id: str, reason: str, detail: str):
        print(f"  → [GUARDIAN] ⚠️ [{node_id}] {reason}: {detail}")
        choice = input("  是否中断？[y/N] ").strip().lower()
        return choice in ("y", "yes")
    
    def emit_completed(self, node_id: str, duration: float):
        print(f"  → [{node_id}] ✅ 完成 ({duration:.0f}s)")
    
    def emit_error(self, node_id: str, error: str):
        print(f"  → [{node_id}] ❌ {error}")
    
    def emit_aggregate(self, summary: str):
        print(f"\n{'='*55}")
        print(f"  汇总结果:")
        print(f"{'='*55}")
        print(summary)
```
